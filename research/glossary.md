# Glossary

Definitions marked **[verify]** require verification against official Databricks documentation.

| Term | Starter definition |
| --- | --- |
| Catalog | Top-level logical container for data assets. **[verify]** |
| Schema | Namespace within a catalog. **[verify]** |
| Delta table | Table using Delta Lake storage format. **[verify]** |
| SQL warehouse | Compute endpoint for SQL workloads. **[verify]** |
| Unity Catalog | Databricks governance layer for data/AI assets. **[verify]** |
| Governed data | Data with controlled access, metadata, and policy. |
| Metric / Measure | Defined business calculation / quantitative field. |
| Dimension | Categorical or descriptive analysis field. |
| Metric view | Governed semantic metric definition. **[verify]** |
| AI/BI Dashboard | Databricks dashboard experience. **[verify]** |
| Databricks Genie | Conversational data-analysis capability. **[verify]** |
| Genie Agent | Configured agent for a business domain. **[verify]** |
| Genie Code | Databricks capability/name requiring official verification. **[verify]** |
| Semantic layer / context | Definitions and relationships that map business language to data. |
| Agent instruction | Behavioral/configuration guidance for an agent. |
| Synonym | Alternate phrase mapped to a business concept. |
| Join relationship | Approved connection between table keys. |
| SQL expression | SQL logic defining a field or calculation. |
| Example SQL / Verified SQL | Illustrative query / independently checked reference query. |
| Trusted asset | Approved source of logic or content. **[verify]** |
| Suggested question | Curated prompt shown to a user. |
| Benchmark | Repeatable set of evaluated test cases. |
| Gold SQL / Gold answer | Approved reference query / expected business response. |
| Natural-language-to-SQL | Translation of a question into SQL. |
| Agent mode | Product behavior/mode requiring verification. **[verify]** |
| Grounding | Constraining output using supplied/approved context. |
| Hallucination | Unsupported generated claim. |
| Non-determinism | Material output variation across similar runs. |
| Ambiguity / Clarification | Multiple plausible meanings / request to resolve them. |
| Refusal | Declining an unsupported or unsafe request with explanation. |
| Human oversight | Human review of definitions, outputs, and decisions. |
| Agent governance / monitoring | Controls and observation for agent operation. |
| Regression testing | Rerunning tests after a change to detect deterioration. |
| Data freshness | How current underlying data is. |
| Confidence / Verification status | Calibrated signal of support / whether logic was checked. |
