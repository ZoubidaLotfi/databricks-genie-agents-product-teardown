# Dashboard Baseline

## Purpose

An AI/BI Dashboard is a controlled, predefined analytics baseline—not the primary product being torn down. It compares the flexibility, speed, trust, and risks of a Genie Agent with a fixed analytics experience.

## Template

Objective: help FlowSync identify usage decline and churn by segment. Proposed pages: executive health; activation/adoption; retention/revenue; support/at-risk accounts. Required KPIs: WAU, MAU, stickiness, activation, churn, MRR, NRR, feature adoption, ticket volume, and health.

Record per task: decision, elapsed time, clicks, required filters, follow-up limitation, usability observation, and confidence. TODO: run matched time-to-insight tests.

| Comparison | Dashboard | Genie Agent |
| --- | --- | --- |
| Strength | Repeatable, visible definitions | Flexible follow-ups and exploration |
| Limitation | Fixed paths and filter work | Interpretation and generated-logic risk |
| Prefer when | KPI monitoring or shared review | Investigative, well-bounded questions |
| Use together | Dashboard establishes baseline; agent explains or explores exceptions | |
